# Yummy Menu UI patterns

Keep customer pages consistent and mobile first.

- Use compact headings, short supporting text, and 16px mobile page gutters.
- Use white cards with a subtle stone border and rounded-xl corners; reuse customer-card.
- Use orange primary actions with rounded-lg corners; reuse customer-primary-button.
- Keep controls at least 44px tall and input text at 16px to support mobile use.
- Use subdued secondary text and icons, and small status badges.
- Avoid nested decorative cards, repeated descriptions, and oversized empty states.
- Keep secondary security settings collapsed initially.
- Preserve the same spacing and controls on desktop; constrain content width instead of stretching forms.
- Keep account editing separate from restaurant orders, rewards, balances, and communication preferences.
